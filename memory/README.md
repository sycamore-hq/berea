# Memory

Reviewed notes that are **not** constitution and **not** a spec.

| Tree | What belongs here |
|---|---|
| `decisions/` | A choice the constitution and specs do not already record |
| `regressions/` | A failure we must not repeat |
| `conventions/` | How we write code or files, if it is not already in a spec |
| `sessions/` | Proposals from an action/chat turn. Not canon. |

Point at writings; do not copy them.

```yaml
---
as_of: 2026-08-28
supersedes:
source: human
confidence: high
status: active
---
```

`status`: active | superseded | rejected | proposal

Action agent: append `sessions/` only. Curator proposes patches for the
other trees. Human merges. Commits start with `memory:`.
