# Memory notes as reviewed facts

Facts that are not constitution and not a spec live under `memory/` with
frontmatter. Personal vault stays out. This writing is specified; it has
no plan yet, so it sits on the next horizon until we plan it.

## Why

Agents need a place for regressions and conventions without stuffing
`AGENTS.md` or copying the constitution.

## Scope

- Frontmatter schema already in `memory/README.md`
- Review gate (curator proposes, human merges)
- FTS over reviewed notes
