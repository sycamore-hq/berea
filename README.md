# Berea

**They received the word with all readiness of mind, and searched the scriptures daily, whether those things were so.**
— Acts 17:11

We don’t take the agent’s word for it. We read the files.

Berea is a lineage for agents that live in a git repo: a skills set, a binary, and a status surface over [GitHub Spec Kit](https://github.com/github/spec-kit). Constitution, specs, plans, and tasks are the writings. Generated context and SQLite are derived. Memory is reviewed before it becomes canon.

This is not CrossR. Different house, different mouth.

## What lives here

| Piece | Role |
|---|---|
| `berea-skills` | How the agent reads and amends the writings |
| `berea` | The binary |
| the Reading | Dashboard + chat over the same files |

Morning asks “what should we work on?” from a generated summary, not from slurp-the-tree. Mid-day, a design conversation becomes `specs/NNN-slug/spec.md`. Afternoon implements a named task and checks the box in `tasks.md`. End of day commits. Tomorrow starts from disk.

## Rule

If it isn’t in the files, it isn’t so.
